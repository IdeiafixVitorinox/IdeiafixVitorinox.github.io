Projetos Destacados

PetRescue

Um site de classificados para resgate e adoção de animais, desenvolvido em .NET framework com uma base de dados SQL Server 2022 para gestão. A PetRescue é uma solução abrangente que permite aos utilizadores registar ocorrências com localização geográfica precisa, fotografias e descrições detalhadas. A plataforma facilita a alteração do estado dos casos (ex.: em avaliação, resgatado, concluído), a publicação de animais para adoção e a partilha nas redes sociais, ampliando o alcance das ocorrências (petrescue.pt está online!).
